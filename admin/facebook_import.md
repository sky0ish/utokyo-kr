# 페이스북 그룹 글·사진 가져오기

대상: <https://www.facebook.com/groups/286637871392457>
(동경대학 한국인 총동문회 · The University of Tokyo Korean Alumni Association)

## 왜 자동으로 못 가져오나

서버에서 이 주소를 그대로 받아보면 **껍데기 HTML만** 내려옵니다.
글 한 건도 들어있지 않습니다(글 데이터 0건, 로그인 확인 페이지로 유도).
페이스북은 비회원·비로그인 상태에는 그룹 내용을 아예 내려주지 않기 때문에,
**회장님이 로그인하신 브라우저 안에서** 긁는 방법밖에 없습니다.

> 계정 아이디·비밀번호는 저에게 알려주지 마세요. 필요 없습니다.

## 하는 방법 (5분)

1. 크롬에서 페이스북에 로그인한 뒤 위 그룹 주소를 엽니다.
   - 가능하면 **디스커션(글) 탭**을 열고, 정렬을 「최신 활동」이 아니라
     기본값 그대로 두세요.
2. `F12` → **Console(콘솔)** 탭을 엽니다.
3. 처음이라면 콘솔에 `allow pasting` 이라고 직접 **타이핑**하고 엔터
   (크롬이 붙여넣기를 막아둔 것을 푸는 절차입니다).
4. `admin/collector.js` 파일 내용을 **전부 복사해서** 콘솔에 붙여넣고 엔터.
5. 오른쪽 아래에 파란 상자가 뜨면서 자동으로 스크롤합니다.
   그룹이 크면 10~20분 걸립니다. 다 끝나면
   `facebook_collected.json` 파일이 자동으로 내려받아집니다.
   - 중간에 그만하려면 **［지금 저장하고 종료］** 버튼을 누르세요.
     그때까지 모은 것만 저장됩니다.
6. 내려받은 `facebook_collected.json` 을 채팅창에 올려주세요.

`admin/bookmarklet.txt` 를 북마크 주소로 넣어 쓰셔도 되지만,
페이스북은 북마클릿을 막아둘 때가 있어 **콘솔 붙여넣기가 확실**합니다.

## 받은 다음 제가 하는 일

- **중복 제외** — 이미 게시판에 있는 글(네이버 밴드 이전분,
  tokyoksa / alumni.tokyoksa 이전분)과 제목·본문을 정규화해 비교하고,
  겹치는 것은 올리지 않습니다.
- **분류 배정** — 글 내용의 키워드로 기존 게시판 분류에 나눠 담습니다.
  총회·정기총회 → 공지 / 포럼·세미나 → 포럼 / 소모임·골프·등산 → 모임 등.
- **사진** — 글에 딸린 사진은 갤러리 분류 체계
  (총회 / 소모임 / 단과대모임 / 포럼·세미나 / 옛날사진 / 일상 / 기타)에
  날짜와 함께 넣습니다.
- 결과는 SQL 파일로 만들어 드리고, 이름이 들어간 파일은
  `.gitignore` 로 저장소에 올라가지 않게 합니다.
